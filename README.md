# 📊 Olist E-Commerce Data Analysis

## 📌 Project Overview

This project focuses on analyzing the **Brazilian E-Commerce Public Dataset by Olist** to evaluate business performance and identify key trends across different areas of an e-commerce business.

The analysis covers **Sales, Customers, Products, Orders, Payments, and Delivery Operations**, using SQL, Excel, and Power BI to explore, transform, and visualize the data.

## 🎯 Business Objectives

- Analyze overall sales performance and order trends.
- Understand customer purchasing behavior.
- Identify top-performing products and categories.
- Evaluate payment methods and transaction patterns.
- Analyze delivery performance and order fulfillment.
- Generate meaningful insights to support business decision-making.
